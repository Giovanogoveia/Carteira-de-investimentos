# Carteira de Investimentos

Sistema web para acompanhamento de uma carteira de investimentos.

## Funcionalidades

- Cadastro de ativos
- Controle de quantidade
- Acompanhamento do patrimônio
- Controle de rendimentos
- Organização por tipo de ativo
- Integração com Supabase

## Tecnologias

- HTML
- CSS
- JavaScript
- Supabase

## Projeto

Sistema desenvolvido para acompanhar e gerenciar investimentos pessoais.
